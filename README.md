# Student Management System

## 📌 About the Project
The Student Management System is a beginner-friendly Python project that allows users to manage student records using a menu-driven program.

## ✨ Features
- **Add Student:** Enter a student's roll number, name, and department.
- **View Students:** Display all stored student records.
- **Search Student:** Find a student using their roll number.
- **Delete Student:** Remove a student record using their roll number.
- **Exit:** Close the program through the menu.

## 🛠️ Technologies Used
- Python 3
- Dictionaries
- Functions
- Conditional Statements (`if`, `elif`, `else`)
- Loops (`while`)
- User Input (`input()`)

## 🚀 How to Run the Project

1. Install Python 3 on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run the following command:

   ```bash
   python student_management.py
   ```

## 💻 Sample Menu

```text
1. Add student
2. View students
3. Search students
4. Delete student
5. Exit

Enter your choice:
```

## 💾 Data Storage
Student records are stored in a Python dictionary while the program runs. The data is temporary and is lost when the program exits.
